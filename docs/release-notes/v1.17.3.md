# Release Notes – v1.17.3

## What is new in v1.17.3

**Update WebDesk with one click – with an automatic backup and a way back.**

---

## 🚀 One-click update

- New page **/update** (linked from the update banner and from *About*). It downloads the release that matches
  your installation, **verifies the SHA-256 checksum**, backs up the program files **and your data**
  (settings, chat history), swaps the files and restarts WebDesk.
- **Automatic rollback:** if the new version does not become healthy (it has to run stably for a minute;
  three starts without that), WebDesk restores the backup and comes back with the old version.
- **Manual rollback:** every backup (the last three are kept) can be restored from the same page.
- Supports the **Windows service**, **systemd** and **manually started** installations
  (Windows, Linux, Raspberry Pi, macOS). **Docker** and development runs are detected and not updated.
- Safety: an update or rollback can only be started **from the machine itself (localhost)**; downloads are
  only accepted from the official release and only with a matching checksum.
- The release now contains a `.sha256` file for every archive and a **self-contained Windows ZIP**
  (used for installations made with the Windows installer).
- ℹ️ The first version with this feature has to be installed manually once; the next update can then be done
  from the page.

---

## 📡 MQTT

- Enabling the **send-topic subscriber** or changing the **topic prefix** now takes effect immediately –
  no restart needed.

---

## 🏓 Ping and firmware 4.40a.10+

- A **ping on a group or broadcast tab** is blocked with a hint: the node firmware only accepts a callsign as ping
  target, so such a ping was never answered.
- The firmware now **refuses broadcast / multicast / its own IP as ext-udp target** (`--extudpip`). The node-connection
  guides (de/en/es/it) point out to enter the specific IP of the WebDesk PC.
