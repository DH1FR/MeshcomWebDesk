# Release Notes – v1.17.2

## What is new in v1.17.2

**The UDP ports are adjustable – WebDesk can now talk to a UDP hub on a different port.**

---

## 🔌 Adjustable UDP ports

- **Listen Port** and **Device Port** (Settings → Connection and per additional node) are editable now
  instead of read-only. Default stays `1799`.
- Made for setups like the **[MeshComUDPBluetoothHub](https://github.com/DH1FR/MeshComUDPBluetoothHub)**,
  which exposes a Bluetooth-connected node as a UDP endpoint on its own port.
- If the new ports do not take effect after saving, restart WebDesk once.
