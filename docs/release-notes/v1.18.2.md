# Release Notes – v1.18.2

## What is new in v1.18.2

**Tidier settings, one "Nodes" section, a friendlier setup wizard, a Docker update that waits for the new image – and two fixes for the settings backup.**

---

## ⚙️ Settings

- **Category tabs and search** – the 29 sections are grouped into five tabs: *Connection*, *Sending & automation*, *Chat & display*, *Integrations* and *System*. A search field filters the sections by title and keywords.
- **Save stays in reach** – the *Save* button sits at the bottom edge of the window instead of at the very end of a long page, and the tab bar with the search field stays visible while you scroll.
- **One "Nodes" section** – *Connection* and *Additional Nodes* are merged. The shared UDP receive settings (*Listen IP* / *Listen Port*) appear once, followed by **one card per node** with the same layout, the primary node first. KISS/TCP, node password and console log sit under *Advanced*. A local hub on port 1798 (e.g. the Bluetooth hub) carries a *Bluetooth hub* badge.
- **The per-node Listen fields are gone** – all nodes share one UDP socket, which was always opened from the global values; the extra fields on the additional nodes had no effect.
- **Add a node with the wizard or manually** – *Add node with wizard* creates a card and starts the setup wizard for it right away, *Add node manually* creates an empty card.

---

## 🧙 Setup wizard

- **Starts with "MeshCom node on WiFi/LAN"**, the usual case. Hub setups pick one of the other options in the first step.
- **The node search is hard to miss** – a spinner, a progress bar (determinate during the network scan) and a highlighted frame show while it runs.
- **One button height** in the wizard, the connection check and the node cards.
- **No confusing old values** – while the wizard runs, the card's own fields are hidden. After *Apply to form* the wizard closes and the card reminds you to save. A node that still has its default name ("Node 2") is named after its callsign.

---

## 🐳 Docker update

- **Waits for the new image** – the update page reported a newer dev build as soon as the commit was on GitHub, but the image is only published by the CI about three minutes later. Updating in that window pulled the old image again and changed nothing, while the page kept saying "Updating …". The check now also asks the registry which commit the published image carries: while it lags behind, the page says the image is still being built, the *Update now* button is disabled, the banner stays hidden, and the update request is refused. If the registry cannot be read, nothing is blocked.

---

## 💛 License key request

- A small form in the coffee dialog and on the About page (name, callsign, *PayPal already donated* or *request payment via Wero*, *Request a license key*) opens a prefilled e-mail to the author in the interface language, followed by the German text. The e-mail is only offered once name and payment option are filled in; a license key needs the callsign as well.

---

## 🔧 Bug Fixes

- **Backup restore lost settings** – restoring a backup reset the appearance (themes and custom themes), the quick texts, the frequency and the system margin to their defaults. They are restored now.
- **"Max. messages per tab" was not saved** – the value never reached the settings file and fell back to 500 after a restart.
- **Connection check texts named a field that no longer exists** – three messages told you to change *Own Callsign* under Settings → Connection, and one to look in the *Connection section*. They now point to **Connection → Nodes** and the card's *Callsign* field.
