# Release Notes – v1.18.3

## What is new in v1.18.3

**Alerts for @mentions and CQ calls to everybody, an unread count in the browser tab, desktop notifications, a better phone-in-landscape layout – and fixes for the map, routing, the MySQL log and Firefox.**

---

## 🔔 Alerts & notifications

- **Alert when somebody mentions you in a group** – a group (or broadcast) message from somebody else that contains `@<your callsign>` (e.g. `@DH1FR-4`) gets a strong row tint, the pill *@ for you*, a short glow and an *@N* badge on the tab. On top of that: a toast *You were mentioned* (a click opens the tab), its own tone and a voice announcement in the five languages, at most once a minute per tab. Matching is case-insensitive and for the whole callsign; `@DH1FR` without SSID matches every callsign with that base. The callsigns of all enabled nodes count. Switch: *Settings → Chat & display → Watchlist → Mention* (default on).
- **CQ calls to everybody** – a CQ sent to everybody (it lands in the *All* tab) now raises the same alert as a CQ in a group: yellow toast *CQ All*, CQ tone, voice announcement and, if enabled, the desktop notification. Switch: *Watchlist → CQ calls to everybody* (default on).
- **Your callsign is always highlighted in message text** – `@DH1FR-4` / `@DH1FR` of your own callsigns is marked in every incoming message, old history and restarts included, with a clearly visible background.
- **Unread count in the browser tab** – the tab title becomes `(3) MeshCom WebDesk`, the favicon gets a red dot, and an installed web app (PWA) shows the number on the app icon. A tab only counts as read while somebody is *really looking* at it. Only messages of existing nodes are counted. Switch: *Settings → Chat & display → Show unread count in browser tab* (default on).
- **Desktop notifications** – operating-system pop-ups for direct messages, mentions, watchlist callsigns, watched groups and CQ calls. They appear **only while nobody is looking at WebDesk**; a click brings the window to the front and opens the matching tab on the right node. Off by default – enable under *Watchlist → Desktop notifications* (the browser asks for permission once). Needs HTTPS or `localhost`.

## 📱 Small screens

- **Phone held sideways** – up to 500 px height in landscape the automatic *compact* mode starts: one-row swipeable tab bar, slim header and send bar, monitor collapsed. At 844×390 the conversation gets 255 px instead of 31 px.
- **iPhone in landscape stays inside the safe area** – nothing is hidden under the notch or the rounded corners any more, the *Send* and *+* buttons are no longer cut off, and toasts sit below the navigation.

---

## ✨ Improvements

- **Hint for an empty telemetry target** – a note under *Telemetry* says that an empty target sends native telemetry (extudp) only, with no text message (#24).

---

## 🔧 Bug Fixes

- **Monitor could not be collapsed or moved in some Firefox browsers** – where Firefox blocks site storage (blocked cookies/site data, strict tracking or fingerprinting protection), the ▼/▲ toggle and the divider did nothing. Both work again; the setting is just not kept after a reload in such a browser.
- **Nodes at the same location on the map** – stations at identical coordinates are spread on a small circle, so each marker stays clickable (#31).
- **Stale routing after a direct reception** – a packet received directly by radio resets the hop count and the last relay path (#31).
- **MySQL monitor storage no longer floods the log** – after a failed write the storage pauses for 60 seconds, logs the first failure once and reports how many messages were skipped.
- **`install.sh` update over a running service** – the service is stopped first, no more *Text file busy* (#18).
- **No scary error at every start** – the harmless antiforgery message *key was not found in the key ring* is no longer logged.
