# Release Notes – v1.14.3

## What is new in v1.14.3

---

## 🌐 Custom Gateway Sources

The **Gateway Source** setting (Settings → Live Map) is no longer limited to OE and DL:

- **New built-in preset**: 🇮🇹 IT – `meshcom.dig-italia.it`
- **New combined / empty options**: "OE + DL" and "None (custom sources only)"
- **Your own sources**: add any number of additional MeshCom dashboards by URL. Each URL must point to the dashboard's `rakgw.html` page. Callsigns from every enabled source are merged into one list.
- Changes now take effect **immediately** instead of after the next 15-minute refresh.

Background: the MeshCom dashboards moved their gateway page from `gateways.html` to `rakgw.html`, and the old OE URL had started returning 404 – so the gateway highlight list had gone empty. All preset URLs are fixed as part of this release.

---

## 🔧 Bug Fixes

- **Map popups/tooltips** on the live map showed hardcoded German text regardless of the selected UI language – they now follow the language setting.
- **Own-position altitude unit** in the MH window was not translated.
- **Quick texts** picked from the flyout are now inserted at the cursor position instead of overwriting whatever is already in the input field.
- **MH monitor header** – restored the missing space between the station count and its label.
