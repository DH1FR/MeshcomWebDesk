# Release Notes – v1.16.0

## What is new in v1.16.0

**Get a phone notification only for direct messages you did not see yourself:** WebDesk now
tells MQTT (and thereby Home Assistant) about unread direct messages to your own callsign.
Plus an unread badge per node and **multiple weekdays** for weekly calendar beacons.

---

## 🔔 MQTT unread alert

- **Why** – the existing `{prefix}/dm/...` topic fires for every message, which is useless as a
  notification trigger when you are sitting in front of WebDesk anyway. The unread alert only fires
  for direct messages **to your own callsign** that nobody has looked at in time.
- **Topics** – `{prefix}/unread/{callsign}` after the wait time (default 60 s; sender, count, latest
  text, RSSI/SNR, relay path), `{prefix}/read/{callsign}` once the conversation has been looked at,
  so the notification can be dismissed again.
- **Settings** – Settings → MQTT → Unread alert: `UnreadAlertEnabled`, `UnreadAlertSeconds`,
  `UnreadActiveSeconds`.
- **Home Assistant** – see [docs/homeassistant-unread-alert.md](https://github.com/DH1FR/MeshcomWebDesk/blob/master/docs/homeassistant-unread-alert.md)
  for payloads and a ready-to-use notification automation.

---

## 👀 "Really looking" detection

- A conversation only counts as read while the chat page is in a **visible** browser tab, the
  conversation is the active tab and there was mouse/keyboard/touch activity within the activity
  window (default 30 s). An idle or hidden browser no longer marks messages as read.
- Bot commands never raise an alert.

---

## 🔢 Unread badge per node

- In multi-node setups the node switcher shows the unread **direct** messages per node
  (groups and broadcast are not counted).

---

## 📅 Calendar beacon

- **Several weekdays** – a weekly entry can be set to any combination of weekdays with
  checkboxes (Settings → Calendar Beacon). Lead times apply to every selected day; existing
  entries keep their weekday.

---

## 🌍 Translations

- New texts and the few still missing ones (MHeard age/role/neighbours, mailbox notice) are
  translated into Italian, Spanish and French.
