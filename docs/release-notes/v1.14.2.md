# Release Notes – v1.14.2

## What is new in v1.14.2

---

## ⌚ New Hardware: T-WATCH-S3

Added `hw_id` 61 (LilyGo T-Watch S3) to the hardware name lookup table.

---

## 🖥️ Console Command Helper

- **`--setlog` toggle** added to the Debug group – shows incoming LoRa packets (Message/Position/Hey/ACK) in an overview, without needing to enable any of the other debug outputs.

---

## 🎨 Hardware-Type Icons

The hardware badge in the MH monitor and the multi-node switcher now shows a small icon for hardware with a distinctive form factor: ⌚ T-WATCH-S3, ⌨️ T-DECK family, 🔌 T-ETH-ELITE. Generic LoRa boards stay text-only. Hidden on small screens in the node switcher to preserve the existing mobile layout.
