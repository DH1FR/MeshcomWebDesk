# Release Notes – v1.15.3

## What is new in v1.15.3

Support for the new **MeshCom firmware 4.35u–4.40a** (new `--mheard` format,
mailbox notices, message retries), a **callsign blacklist**, **UI languages as
plain JSON files** with complete Italian/Spanish/French translations, and fixes
for ACK ticks and sending with KISS.

---

## 📡 MeshCom firmware 4.40a

- **`--mheard` window** – the node now answers `--mheard` with `[MH] key=value`
  lines instead of an ASCII table. The MHeard popup (NET Console and Command
  Helper) understands the new format (the old table still works) and shows the
  new columns **Age**, **Role** (N = node, R = relay), **NB** (bidirectional
  neighbours) and **GW**.
- **Map: role, neighbours, gateway** – after a `--mheard` answer the map popups
  of the listed stations show **📡 Relay / Node**, the number of bidirectional
  neighbours and a **GW** badge. ext-udp does not carry this data, so it is
  refreshed whenever the MHeard popup is opened.
- **Mailbox custody notice (store-and-forward)** – a `:stoNNN` text from a
  mailbox node is no longer shown as a chat message: it appears in the monitor
  as `STO` and the matching outgoing DM gets a **📬** tick ("held by mailbox
  node X"). The real ACK still turns it into ✓✓.
- **Message retries (4.35u+)** – the node re-sends an unacknowledged DM up to 3×
  and encodes the attempt in bits 10–11 of the `msg_id`; these copies are now
  recognised as the same message.

---

## 🚫 Blacklist

New **Settings → 🚫 Blacklist** (callsign list, one per line). Messages from
these stations appear **only in the monitor** – no chat or group tab, no
direct-message/watchlist/CQ/bot handling, no webhook/MQTT. `DH1FR` or `DH1FR-*`
blocks every SSID of that callsign, `DH1FR-55` only exactly that one. The MH
list and the map are still updated.

---

## 🌍 Translations as language files

Italian, Spanish and French are no longer compiled in but plain JSON files
(`MeshcomWebDesk/Languages/*.json`, English text → translation). Drop a `xx.json`
into `<DataPath>/languages/` (Docker: `./data/languages/`) to **add a language or
override single strings**; a "Reload language files" button in Settings →
Language avoids a restart. Missing strings fall back to English.
`python scripts/check_translations.py` reports missing/unused texts; see
`docs/translations.md`. The dictionaries were also **completed** (about 560 Italian/Spanish and
220 French texts were missing) and texts with values are now translatable.

---

## 🔧 Improvements and bug fixes

- **Monitor: long texts no longer cut off** – long messages wrap onto further
  lines instead of ending with an ellipsis.
- **ACK ticks missing / wrong message ticked** – an incoming ACK is now applied
  to the newest still-unacknowledged message with that sequence number (numbers
  wrap at 999 and are reused) instead of the oldest one.
- **Sending impossible with KISS enabled and an SSID > 15** – such callsigns
  (e.g. `DH1FR-99`) cannot be encoded in AX.25; WebDesk now sends over ext-udp
  for them, so the node's echo arrives again.
- **Doc links** – the node-connection guide link no longer 404s for French.
