# Release Notes – v1.18.4

## What is new in v1.18.4

**Optional password protection for the web UI, all gateway dashboards by default, a variable button and emoticon conversion in the send bar, tabs that open at the first unread message, a new app icon – and fixes for KISS, telemetry and small screens.**

---

## 🔒 Access protection

- **Optional shared password** – **Settings → System → Access protection**: *Only from other devices* (recommended – the PC running WebDesk gets in without a password, phones, tablets and other PCs log in once per device and stay logged in for 90 days), *Always* or *Off* (default, nothing changes for existing installations). The password is stored only as a salted PBKDF2 hash in `<DataPath>/access.json`; wrong passwords are throttled per address. A standalone login page (`/login`) is shown in the interface language; `POST /api/telemetry` keeps its own `X-Api-Key`. Protected http requests from other devices are redirected to https when WebDesk also listens on it.
- **Forgot the password?** Start WebDesk once with `--reset-password` (switches the protection off; `--reset-password NEWPASSWORD` sets a new one), in Docker `docker exec <container> ./MeshcomWebDesk --reset-password`, or start the container once with `MESHCOM_RESET_ACCESS=1`.

---

## 🛰️ Gateways

- **All gateway dashboards are queried by default** – the gateway highlight list and the "last seen on the server" presence now read OE, DL, IT, HB and SP instead of OE only. The dashboards hardly overlap (about 880 gateways in total, OE alone knows only about 480). New option **Settings → Gateway source → All**, now the default. **At the update every installation is switched to *All* once**, whatever was selected before; after that the choice is yours.

---

## ✍️ Writing messages

- **`{}` button in the send bar** – inserts the current value of a variable (e.g. `{callsign}`, `{locator}`, `{last-qso}`) at the cursor, from a scrollable table with descriptions.
- **Text emoticons become emoji** – `;-)`, `:D`, `<3` and similar are converted while typing, once a space follows, and the last word when the message is sent. Switch: *Settings → Chat & Monitor* (on by default). Also works on iOS keyboards.
- **Bot commands work with `--` again** – besides `>` the bot answers direct messages starting with `--` or `—` (em dash) and a letter: `--ping` and `>ping` are the same, likewise `--version`, `--help`, `--time`, … Useful for devices without a `>` key, e.g. the LilyGo T-Deck.

---

## 🔔 Unread messages

- **Tabs open at the "New messages" line** – a tab with many unread messages opens where the new messages start; a button *↑ N unread* jumps back. Unread counts survive a restart.
- **Unread badge shows total and direct/mention count** – in the browser tab title, in the favicon dots and on the app icon badge.

---

## 🎨 Look & small screens

- **New app icon** – a new, higher-contrast mesh-network icon for the favicon, PWA manifest, iOS touch icon, Windows `app.ico`, the header, the About page and desktop notifications.
- **Tab bar switches to a one-row swipeable layout when too many tabs** would take the chat area, on any screen size.
- **Header title fits small and mid-size screens**, and the About, Update and Clear pages and the QR dialog scroll on low screens.

---

## 🔧 Bug Fixes

- **`>rx` or `--rx` over KISS** answered "signal unknown" on the first try; the bot now waits up to 1 s for the signal values (RSSI/SNR).
- **extudp telemetry stays enabled across restarts** – a missing node echo no longer switches the setting off for good.
- **KISS relay hops with a clamped SSID** (−15) showed as `-?`; they are repaired from the full ext-udp path.
- **Unread favicon dots show again.**
