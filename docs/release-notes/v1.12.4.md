# Release Notes – v1.12.4

## What is new in v1.12.4

---

## ⚙️ Settings: Path Validation & Error Reporting

DataPath and LogPath are now actively checked for problems when you open the Settings page and again after every save.

- **Writability check** – the app probes whether it can actually write to each directory. If not, an amber warning appears directly above the Save button so you can't miss it.
- **Inline syntax validation** – if you type a path with invalid characters, a misplaced colon, or a path that is too long, a red error message appears immediately below the input field and the Save button is disabled until the path is corrected.
- **Resolved absolute path** – the effective absolute path is shown below each input. When you enter a relative path such as `data`, you can see at a glance where files will actually be written.
- **DataPath restart notice** – a hint is shown when the entered DataPath differs from the currently active one, since the change only takes effect after a restart.

---

## 🖥️ Console Command Helper

- **`--setcont` toggle** added to the Debug group.
- State is now reset correctly when the node disconnects, preventing stale values from a previous session.

---

## 🌐 `--gateway` Command

`srv OE` and `srv DL` options added to select the OE or DL gateway server directly from the console.

---

## 🐛 Bug Fixes

- **`--weather` with Weather API disabled** – the full telemetry string is now returned correctly even when the Weather API provider is turned off.
- **MH / Help popup** – data is displayed correctly when the telnet line ring-buffer has reached the 500-entry cap or has wrapped around.
- **Message deduplication** – the deduplication window has been extended to 30 minutes; cross-format duplicate detection added; dedup keys are now global across all configured nodes instead of per-node.
- **Bot commands** – `--ping` and `--version` are available without BotEnabled (v1.12.3 behaviour restored); `--help` is available even when the bot is disabled.
- **CallsignPopup** – name fields are reset correctly when the displayed callsign changes.
