# Release Notes – v1.17.0

## What is new in v1.17.0

**Full support for the MeshCom 4.40a delivery status, APRS symbols on the map and a quick
"is this station reachable?" dot on every direct chat tab.**

---

## 📬 Node delivery status (firmware 4.40a)

- The node reports the fate of every message you send as a JSON `{"type":"ack","msg_id":…,"status":…}`
  datagram. WebDesk matches it to your outgoing message via the `msg_id` of the node echo.
- A gateway or destination ACK sets the delivery ticks (`☁️✓` / `✓✓`) with the round-trip time,
  **`❌` shows that the node gave up** after its retransmit ladder, `📬` names the store node that holds
  the message. Unknown `msg_id`s (messages sent from another client) are ignored.

---

## 🗺️ APRS symbols on the map

- Stations that send an APRS symbol get a glyph in front of the callsign on the map (🚗 🏠 📡 🚲 ⛵ 🌦️ …)
  and an `APRS` badge in the popup. The dot keeps its signal colour, relay ring and gateway marker.
- The MHeard station card additionally shows the LoRa modulation ID (`MOD`), the remaining hop
  budget (`Hops`) and the APRS symbol.

---

## 🟢 Online indicator on direct chat tabs

- A coloured dot (green / yellow / grey) shows whether a station is probably reachable; `📡` = heard
  directly by radio. Based on the dashboard's `nodes.html` and the local MH list.
- Settings → Chat & Monitor: on/off and thresholds (default 45 / 120 minutes).

---

## 📍 Maidenhead locators

- A locator in chat or monitor links to the map and highlights its square; hovering shows a preview
  map. The map legend is collapsed by default.

---

## 🌐 Gateway presets

- New presets **HB** (`meshcom.emcomm.ch`) and **SP** (`sp.meshcom.pl`) in Settings → Gateway Source.
- **Fix:** the DL preset pointed to a URL that answers 404, so no DL gateways were highlighted. Custom
  sources saved with the old URL are repaired automatically.
