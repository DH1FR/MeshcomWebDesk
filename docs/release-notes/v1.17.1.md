# Release Notes – v1.17.1

## What is new in v1.17.1

**A compact display mode for tiny touch screens, fewer false CQ alerts and a security update for the MySQL driver.**

---

## 📱 Compact display mode

- Made for small displays such as 480×320 touch screens: slim icon-only header, single-row tabs,
  finger-sized send bar, a node dropdown in the header, a compact MH list (callsign, name, last heard,
  distance, RSSI, SNR), a one-row map control bar and a single-column Settings page.
- Auto-detected for very small viewports, or chosen in **Settings → Appearance → display mode**
  (auto / normal / compact, stored per browser). `?display=compact|normal|auto` forces it for the
  current browser tab only.
- Compact mode survives Blazor page navigation; the monitor toggle, tabs and send bar stay reachable.

---

## 📣 CQ detection

- Messages addressed to one station (`@DH1FR …`) and "CQ" glued to `/` or `-` (the magazine "CQ/DL")
  no longer count as a CQ call. Real calls such as `CQ de OE6TZD` are still detected.

---

## 🔒 Security

- **MySqlConnector 2.6.1** fixes GHSA-473q-m89c-ghf8: with `SslMode=VerifyCA`/`VerifyFull` and no `SslCa`
  the DB password could be sent in clear text before the certificate was verified. The default mode and
  local connections were not affected.
