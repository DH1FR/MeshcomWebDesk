# Release Notes – v1.15.4

## What is new in v1.15.4

A small fix release: **no more fake group tabs** for messages to other stations,
**group labels pre-filled** on a fresh installation, the **WebDesk icon** for the
Windows installer shortcuts and a tidier **license badge** in the header.

---

## 💬 Chat tabs

- **No fake group tabs for other stations** – a message addressed to a callsign
  that is not yours (e.g. `To=DL6WAB`, heard on the mesh/RF) was taken for a
  group and opened a tab `#DL6WAB` whenever the group filter was off (the
  default). A callsign-like destination is never a group any more: such messages
  appear only in the monitor – no tab, no CQ alert.
- **Group labels on a fresh installation** – the tabs showed no short names
  (DACH, EU, …) because the label list started empty. A fresh installation is
  pre-filled with the official MeshCom list again; once you have saved settings,
  an emptied list stays empty.

---

## 🪟 Windows

- **Installer icon** – the exe now carries the WebDesk icon, and the desktop,
  start-menu and autostart shortcuts as well as the entry in "Apps & features"
  use it instead of the Windows default.

---

## 🎨 UI

- **License badge** – when the header line is full, the callsign of
  "Licensed for" now wraps below the badge text instead of jumping to the start
  of the title line.
