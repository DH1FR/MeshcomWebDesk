# Node verbinden

WebDesk spricht mit einem MeshCom-Node über das **EXTUDP-Protokoll** (JSON über UDP) oder – bei Nodes mit
KISS-Firmware – über **KISS/TCP**. Wie du den Node dafür einrichtest, steht in den ausführlichen Anleitungen:

- [Node-Verbindung (Deutsch)](https://github.com/DH1FR/MeshcomWebDesk/blob/master/docs/node-connection-de.md)
- [KISS/TCP-Anleitung (Englisch)](https://github.com/DH1FR/MeshcomWebDesk/blob/master/docs/kiss-tcp-guide-en.md)

Ein Node **ohne WLAN** (z. B. Heltec T114) lässt sich über Bluetooth mit dem
[MeshCom UDP Bluetooth Hub](https://github.com/DH1FR/MeshComUDPBluetoothHub) anbinden.
