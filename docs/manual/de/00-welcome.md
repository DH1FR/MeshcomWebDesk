# Willkommen

Dieses Handbuch erklärt **MeshCom WebDesk** Schritt für Schritt – von der Installation bis zu den Automatiken.
Es ist in der Anwendung über **❓ Hilfe** erreichbar und funktioniert auch ohne Internet.
Dieselben Dateien liegen auf GitHub unter [docs/manual](https://github.com/DH1FR/MeshcomWebDesk/tree/master/docs/manual).

> 🚧 **Das Handbuch wächst.** Die Kapitel kommen nach und nach; bis dahin hilft das
> [README](https://github.com/DH1FR/MeshcomWebDesk#readme) mit der vollständigen Funktionsübersicht.

## Aufbau

| Kapitel | Inhalt |
|---|---|
| Willkommen | Dieses Kapitel |
| [Schnellstart und Installation](01-install.md) | WebDesk installieren und starten (Windows, Linux, Docker, macOS) |
| [Node verbinden](02-connect-node.md) | Wie WebDesk mit einem MeshCom-Node spricht, Verbindung prüfen |
| [Die Oberfläche](03-interface.md) | Chat, MH-Liste, Monitor und Statusleiste |
| [Nachrichten schreiben](04-writing-messages.md) | Länge, Variablen, Schnelltexte, Emoticons |

## Schreibweisen

- **Fett** sind Bezeichnungen aus der Oberfläche, z. B. **Einstellungen → System**.
- `Schreibmaschinenschrift` sind Eingaben, Dateinamen und Befehle, z. B. `>ping` oder `--reset-password`.
