# Willkommen

Dieses Handbuch erklärt **MeshCom WebDesk** Schritt für Schritt – von der Installation bis zu den Automatiken.
Es ist in der Anwendung über **❓ Hilfe** erreichbar und funktioniert auch ohne Internet.
Dieselben Dateien liegen auf GitHub unter [docs/manual](https://github.com/DH1FR/MeshcomWebDesk/tree/master/docs/manual).

## Schreibweisen

- **Fett** sind Bezeichnungen aus der Oberfläche, z. B. **Einstellungen → System**.
- `Schreibmaschinenschrift` sind Eingaben, Dateinamen und Befehle, z. B. `>ping` oder `--reset-password`.
