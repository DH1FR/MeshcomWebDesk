# Connecting the node

WebDesk talks to a MeshCom node through the **EXTUDP protocol** (JSON over UDP) or – for nodes running the KISS
firmware – through **KISS/TCP**. How to set up the node for this is described in the detailed guides:

- [Node connection (English)](https://github.com/DH1FR/MeshcomWebDesk/blob/master/docs/node-connection-en.md)
- [KISS/TCP guide](https://github.com/DH1FR/MeshcomWebDesk/blob/master/docs/kiss-tcp-guide-en.md)

A node **without WiFi** (e.g. Heltec T114) can be connected over Bluetooth with the
[MeshCom UDP Bluetooth Hub](https://github.com/DH1FR/MeshComUDPBluetoothHub).
