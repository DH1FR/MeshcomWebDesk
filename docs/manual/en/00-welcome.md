# Welcome

This manual explains **MeshCom WebDesk** step by step – from installation to the automations.
It is available inside the application under **❓ Help** and works without an internet connection.
The same files are on GitHub in [docs/manual](https://github.com/DH1FR/MeshcomWebDesk/tree/master/docs/manual).

## Conventions

- **Bold** is a name from the user interface, e.g. **Settings → System**.
- `Monospace` is input, file names and commands, e.g. `>ping` or `--reset-password`.
